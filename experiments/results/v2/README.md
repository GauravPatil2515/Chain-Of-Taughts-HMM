# Experiment Results

## Directory Structure

```
experiments/results/v2/
├── baseline_comparison.json      # All method comparisons
├── bootstrap_cis.json            # 95% confidence intervals
├── effect_sizes.json             # Cohen's d, Cliff's delta
├── roscoe_scores.json            # ROSCOE baseline results
├── picsar_scores.json            # PiCSAR baseline results
├── neural_hmm_scores.json        # Neural-HMM hybrid results
├── rejection_sampling.json       # Week 9-10 results
├── figures/
│   ├── correlation_comparison.png
│   ├── auc_comparison.png
│   ├── transition_heatmap.png
│   └── score_distributions.png
└── pipeline_summary.json         # Master summary
```

## Key Result Files

| File | Description | Generated By |
|------|-------------|------------|
| `baseline_comparison.json` | Correlation, AUC, p-values for all methods | `run_baseline_eval.py` |
| `bootstrap_cis.json` | 95% CI for headline numbers | `bootstrap_ci.py` |
| `effect_sizes.json` | Cohen's d for score differences | `effect_size.py` |
| `roscoe_scores.json` | ROSCOE semantic scores | `roscoe_baseline.py` |
| `picsar_scores.json` | PiCSAR log-probability scores | `picsar_baseline.py` |

```json
{

    {"method": "hmm_score", "correlation": 0.21, "p_value": 0.008},
    {"method": "diversity_score", "correlation": 0.28, "p_value": 0.015}

    {"method": "hmm_score", "auc": 0.62, "accuracy": 0.58},
    {"method": "random", "auc": 0.50, "accuracy": 0.50}
  ]

```

## Statistical Reporting

When reporting results in paper:
- Use bootstrap CIs: `r=0.21 [95% CI: 0.09, 0.32]`
- Report effect sizes alongside p-values
- All FDR-corrected for multiple comparisons
